# Local patches to the submodules

Applied on top of the pinned submodules (ModernGekko `edd460a`, its vendored RecompCore `10f7ac4fe4`).
The native Windows build ([development notes](../docs/development-notes.md#native-windows-build)) and the Android build
([development notes](../docs/development-notes.md#android)) use the same patches.
Re-apply after a fresh checkout with `tools/apply-patches.sh` (CI runs it; the RecompCore order is in
`patches/recompcore.series`), which does the equivalent of the list below. After editing a submodule,
`tools/regen-recompcore-patch.sh NAME [NEW_FILE...]` rewrites one RecompCore patch from the working copy
(only that patch's own changes) and `tools/check-patches.sh` proves the whole set still reproduces the
working copies:

target, not by `ninja dolrecomp`.
